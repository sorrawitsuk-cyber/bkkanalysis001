# Analysis Questions

> [!info] วัตถุประสงค์
> ใช้รวบรวมคำถามวิเคราะห์ที่โปรเจกต์ต้องการตอบ เพื่อใช้กำหนดข้อมูล วิธีวิเคราะห์ และรูปแบบการนำเสนอ

---

## คำถามระดับภาพรวม กทม.

- กรุงเทพมหานครมีการเปลี่ยนแปลงเชิงพื้นที่อย่างไรในแต่ละปี
- พื้นที่สีเขียวเพิ่มขึ้นหรือลดลง
- พื้นที่เมืองหรือสิ่งปลูกสร้างมีแนวโน้มเพิ่มขึ้นในเขตใด
- พื้นที่ใดมีแนวโน้มอุณหภูมิพื้นผิวสูงขึ้น
- เขตใดมีการเปลี่ยนแปลงเด่นชัดที่สุด

---

## คำถามระดับรายเขต

- แต่ละเขตมีค่าดัชนีจาก Google Earth Engine แตกต่างกันอย่างไร
- เขตใดมีค่า NDVI ต่ำ
- เขตใดมีค่า NDBI สูง
- เขตใดมีค่า LST สูง
- เขตใดเปลี่ยนแปลงมากที่สุดเมื่อเทียบกับปีก่อน
- เขตใดควรถูกจัดเป็นพื้นที่ติดตามพิเศษ

---

## คำถามเกี่ยวกับ Traffy Fondue

- เขตใดมีจำนวนเรื่องร้องเรียนมากที่สุด
- ประเภทปัญหาใดพบบ่อยที่สุดในแต่ละเขต
- จุดร้องเรียนกระจุกตัวอยู่บริเวณใด
- เรื่องร้องเรียนสัมพันธ์กับลักษณะพื้นที่หรือไม่
- เขตที่มี LST สูง มีปัญหาร้องเรียนประเภทใดมาก
- เขตที่มีพื้นที่สีเขียวน้อย มีเรื่องร้องเรียนมากกว่าหรือไม่

---

## คำถามเชิงนโยบาย

- ข้อมูลเชิงพื้นที่ช่วยระบุพื้นที่ที่ควรปรับปรุงได้อย่างไร
- ควรจัดลำดับความสำคัญของเขตอย่างไร
- ข้อมูลใดเหมาะสำหรับสื่อสารกับผู้บริหาร
- ข้อมูลใดเหมาะสำหรับเจ้าหน้าที่ปฏิบัติงาน
- Dashboard ควรแสดง insight ใดเป็นอันดับแรก

---

## Output ที่ควรตอบคำถามเหล่านี้

| คำถาม                          | Output ที่เหมาะ            |
| ------------------------------ | -------------------------- |
| เขตใดเปลี่ยนแปลงมากที่สุด      | Ranking Chart              |
| ค่าแต่ละเขตต่างกันอย่างไร      | Choropleth Map             |
| เปลี่ยนแปลงรายปีอย่างไร        | Line Chart                 |
| จุดปัญหาอยู่ตรงไหน             | Point Map / Heatmap        |
| ปัญหาสัมพันธ์กับพื้นที่หรือไม่ | Scatter Plot / Correlation |
| เขตใดควรติดตาม                 | Priority Table             |

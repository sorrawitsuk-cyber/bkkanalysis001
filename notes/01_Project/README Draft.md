# bkkanalysis001

โปรเจกต์วิเคราะห์ข้อมูลเชิงพื้นที่ของกรุงเทพมหานคร โดยใช้ข้อมูลจาก Google Earth Engine เพื่อเปรียบเทียบการเปลี่ยนแปลงรายปีและรายเขตของ กทม. พร้อมวางแผนต่อยอดการวิเคราะห์ร่วมกับข้อมูล Traffy Fondue และ Open Data อื่น ๆ

---

## Project Goal

โปรเจกต์นี้มีเป้าหมายเพื่อพัฒนากระบวนการวิเคราะห์ข้อมูลเชิงพื้นที่ที่ช่วยให้เห็นแนวโน้มและความเปลี่ยนแปลงของพื้นที่กรุงเทพมหานครในแต่ละปีและแต่ละเขต โดยใช้ข้อมูลจาก Google Earth Engine เป็นฐานข้อมูลหลัก

ในอนาคตจะนำข้อมูลจาก Traffy Fondue และ Open Data ของกรุงเทพมหานครมาร่วมวิเคราะห์ เพื่อค้นหา insight เชิงลึกเกี่ยวกับปัญหาเมือง สภาพพื้นที่ และปัจจัยแวดล้อมที่เกี่ยวข้อง

---

## Main Data Sources

- Google Earth Engine
- Traffy Fondue
- Bangkok Open Data
- Bangkok District Boundary
- GIS Layers เช่น ถนน คลอง ชุมชน สวนสาธารณะ

---

## Expected Outputs

- แผนที่เปรียบเทียบรายเขต
- ตารางสรุปรายปี
- Dashboard เชิงวิเคราะห์
- กราฟแนวโน้มและ ranking
- Insight สำหรับสนับสนุนการวางแผนเมือง

---

## Analysis Scope

- วิเคราะห์รายปี
- วิเคราะห์รายเขต
- วิเคราะห์การเปลี่ยนแปลงเชิงพื้นที่
- วิเคราะห์ความสัมพันธ์กับข้อมูลร้องเรียนเมือง
- วิเคราะห์ร่วมกับข้อมูล Open Data

---

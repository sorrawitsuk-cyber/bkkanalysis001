# Layer Plan  
  
> [!info] วัตถุประสงค์  
> ใช้วางแผน layer ที่จะใช้ในแผนที่และ Dashboard ของโปรเจกต์  
  
---  
  
## Base Layer  
  
| Layer | ประเภท | ใช้ทำอะไร |  
|---|---|---|  
| Light Basemap | Raster/Tile | แผนที่พื้นหลังแบบสะอาด |  
| Satellite Basemap | Raster/Tile | ตรวจสอบพื้นที่จริง |  
| Administrative Boundary | Polygon | แสดงขอบเขตพื้นที่ |  
  
---  
  
## Main Analysis Layers  
  
| Layer | ประเภท | แหล่งข้อมูล | ใช้ทำอะไร |  
|---|---|---|---|  
| เขต กทม. | Polygon | Open Data / GIS | วิเคราะห์รายเขต |  
| GEE Index รายเขต | Polygon/Table | Google Earth Engine | แสดงค่าดัชนีรายเขต |  
| Traffy Complaints | Point | Traffy Fondue | แสดงจุดปัญหาเมือง |  
| Open Data Context | Point/Line/Polygon | Open Data | เพิ่มบริบทพื้นที่ |  
  
---  
  
## Google Earth Engine Layers  
  
| Layer | ความหมาย | รูปแบบแสดงผล |  
|---|---|---|  
| NDVI | พื้นที่สีเขียว/พืชพรรณ | สีเขียวเข้ม-อ่อน |  
| NDBI | พื้นที่สิ่งปลูกสร้าง | สีส้ม/น้ำตาล |  
| LST | อุณหภูมิพื้นผิว | สีเหลือง-แดง |  
| NDWI / Water Index | พื้นที่น้ำ | สีฟ้า |  
| Land Cover | ประเภทการใช้ที่ดิน | สีแยกประเภท |  
  
---  
  
## Traffy Layers  
  
| Layer | ความหมาย | รูปแบบแสดงผล |  
|---|---|---|  
| All Complaints | จุดร้องเรียนทั้งหมด | จุดสีเทา/โปร่ง |  
| Complaint by Type | จุดแยกตามประเภท | สีตามประเภท |  
| Unresolved Complaints | เรื่องที่ยังไม่เสร็จ | จุดสีแดง |  
| Complaint Density | ความหนาแน่นเรื่องร้องเรียน | Heatmap |  
| District Summary | จำนวนเรื่องรายเขต | Choropleth |  
  
---  
  
## Open Data Layers ที่ควรพิจารณา  
  
| Layer | ใช้วิเคราะห์ร่วมกับ |  
|---|---|  
| ถนน | ปัญหาถนน / การเข้าถึง / เมืองหนาแน่น |  
| คลอง | น้ำท่วม / น้ำเสีย / พื้นที่สีฟ้า |  
| สวนสาธารณะ | NDVI / พื้นที่สีเขียว |  
| ชุมชน | ปัญหาเมือง / ความเปราะบาง |  
| โรงเรียน | บริบทบริการสาธารณะ |  
| โรงพยาบาล / ศูนย์บริการ | การเข้าถึงบริการ |  
| จุดเสี่ยงน้ำท่วม | Traffy ประเภทน้ำท่วม |

## หลักการออกแบบ Layer  
  
> [!tip] แนะนำ  
> - อย่าเปิด layer มากเกินไปพร้อมกัน  
> - ใช้สีให้สื่อความหมาย เช่น เขียว = พื้นที่สีเขียว, แดง = ความร้อน/ปัญหา  
> - แยก layer วิเคราะห์หลักกับ layer บริบท  
> - ทำ filter ตามปี เขต และประเภทปัญหา  
> - popup ควรสั้นและอ่านง่าย

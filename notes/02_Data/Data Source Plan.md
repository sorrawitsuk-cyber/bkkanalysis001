# Data Source Plan

> [!info] วัตถุประสงค์
> ใช้วางแผนแหล่งข้อมูลที่จะใช้ในโปรเจกต์ ทั้งข้อมูลหลัก ข้อมูลเสริม และข้อมูลในอนาคต

---

## 1. Google Earth Engine

### บทบาท

ใช้เป็นแหล่งข้อมูลหลักสำหรับวิเคราะห์การเปลี่ยนแปลงเชิงพื้นที่ของกรุงเทพมหานครในแต่ละปีและแต่ละเขต

### ตัวอย่างข้อมูลที่อาจใช้

| Dataset / Index | ใช้วิเคราะห์ | หมายเหตุ |
|---|---|---|
| NDVI | พื้นที่สีเขียว / พืชพรรณ | ใช้ดูแนวโน้มพื้นที่สีเขียว |
| NDBI | พื้นที่สิ่งปลูกสร้าง | ใช้ดูความเป็นเมือง |
| LST | อุณหภูมิพื้นผิว | ใช้วิเคราะห์ heat island |
| NDWI | พื้นที่น้ำ / ความชื้น | อาจใช้กับคลอง/น้ำท่วม |
| Land Cover | ประเภทการใช้ที่ดิน | ใช้ดูภาพรวมพื้นที่ |

---

## 2. Traffy Fondue

### บทบาท

ใช้เป็นข้อมูลปัญหาเมืองที่ประชาชนแจ้งเข้ามา เพื่อนำมาวิเคราะห์ร่วมกับข้อมูลเชิงพื้นที่

### มิติที่ควรวิเคราะห์

- จำนวนเรื่องร้องเรียนรายเขต
- ประเภทปัญหาที่พบบ่อย
- จุดกระจุกตัวของปัญหา
- ระยะเวลาแก้ไขปัญหา
- เรื่องที่ยังไม่จบ
- ความสัมพันธ์กับสภาพพื้นที่จาก Google Earth Engine

---

## 3. Open Data กทม.

### บทบาท

ใช้เป็นข้อมูลบริบทเพื่ออธิบายสาเหตุหรือปัจจัยที่เกี่ยวข้องกับการเปลี่ยนแปลงของพื้นที่และปัญหาเมือง

### ชุดข้อมูลที่ควรพิจารณา

| ชุดข้อมูล | ใช้วิเคราะห์ร่วมกับ |
|---|---|
| ขอบเขตเขต | ทุกการวิเคราะห์รายเขต |
| ถนน | ปัญหาถนน / ความหนาแน่นเมือง |
| คลอง | น้ำท่วม / น้ำเสีย / พื้นที่น้ำ |
| สวนสาธารณะ | พื้นที่สีเขียว / NDVI |
| ชุมชน | ปัญหาเมือง / ความเปราะบาง |
| ประชากร | normalize ค่าเป็นต่อประชากร |
| จุดบริการสาธารณะ | การเข้าถึงบริการ |
| พื้นที่เสี่ยงน้ำท่วม | Traffy ประเภทน้ำท่วม |
